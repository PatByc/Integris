# Product Brief

## One-liner

Integris helps Polish companies convert invoice documents into validated FA(3) XML and submit them to KSeF without replacing their existing ERP/accounting workflows.

## Target user

Primary users:

- accounting teams
- finance operations teams
- CFO-controlled back-office teams
- Polish SMEs and mid-market companies
- companies using legacy ERP/accounting systems
- companies with PDF, Excel, email, or export-based invoice workflows

Secondary users:

- accounting offices
- ERP integrators
- implementation partners

## Problem

Polish companies must adapt to KSeF, but many operate on:

- legacy ERP systems
- desktop accounting software
- manual PDF workflows
- Excel-based invoice operations
- systems without modern APIs
- fragmented approval and correction processes

They do not want to replace ERP systems or rebuild internal workflows.

They need a reliable bridge from current invoice inputs to KSeF-compatible submission.

## Core value proposition

Integris provides an operational middleware layer that turns messy invoice inputs into validated, reviewable, auditable KSeF submissions.

The value is not “AI accounting”.

The value is:

- less manual invoice work
- fewer KSeF submission errors
- no ERP replacement
- clear human approval workflow
- traceable audit history
- reliable document processing pipeline

## MVP outcome

The MVP is successful when a user can:

1. Upload a PDF invoice.
2. Run OCR on the PDF.
3. Extract structured invoice data into JSON.
4. Validate required fields and totals.
5. Review and correct the extracted data.
6. Approve the invoice.
7. Generate FA(3)-compatible XML.
8. Submit to KSeF sandbox.
9. See submission status, errors, and audit history.

## MVP inputs

Start with:

- PDF invoice upload

Later:

- email inbox
- watched folder
- Excel
- ERP exports

## MVP outputs

- structured invoice JSON
- validation errors/warnings
- human review screen
- FA(3) XML
- KSeF submission status
- audit trail

## Non-goals

Do not build in MVP:

- full ERP integration
- desktop app
- RPA
- accounting chatbot
- AI copilot
- agentic autonomous accountant
- payment processing
- invoice creation from scratch
- analytics dashboard
- multi-country compliance
- mobile app
- custom OCR engine

## Success criteria

MVP quality should be judged by:

- extraction usefulness
- validation reliability
- review speed
- clean state management
- auditability
- KSeF sandbox submission reliability
- low operational support burden
